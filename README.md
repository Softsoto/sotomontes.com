Sitio personal y portafolio. HTML y CSS estáticos publicados con GitHub Pages.

## Agregar un proyecto

1. Añade una entrada en `projects.mjs`. Si tiene imagen, ponla en `assets/img` (JPG, 800×500).
2. Ejecuta `node build.mjs`.
3. Haz commit y push a `main`. La web se actualiza sola en un par de minutos.
